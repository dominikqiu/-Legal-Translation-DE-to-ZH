## 五、Gesetz / Recht 区分

| 德文 | 正确译名 | 说明 |
|------|---------|------|
| Gesetz | **制定法** | 仅在固定搭配中保留"法律"（如 Rechtsgeschäft 法律行为） |
| Recht | **法** | 客观意义上的法 |
| Gesetzesinterpretation | **制定法阐释** | ~~法律解释~~ |
| Ratio legis | **制定法理由** | ~~法律理由~~ |
| Ratio iuris | **法的理由** | ~~法理~~ |
| Rechtsquellenlehre | **法渊源理论** | ~~法源理论~~ |
| Rechtsprinzip | **法原则** | ~~法律原则~~ |

> **注意**：此区分适用于法律史 / 方法论著作。在纯粹的 BGB 民法教义学文本中，Gesetz 通常译为"法律"即可。
