# 中德法学翻译语料库：逻辑关系处理规范

> **定位**：`legal-de-to-zh` skill 的配套语料库，规范德译汉时**转折、因果、总结**三类逻辑关系的处理习惯。
> **效力**：翻译时优先于通用文风直觉；与 SKILL.md「连接词偏好／逻辑关系处理细则」并用。
> **范围**：只收**跨题材通用**的语言处理规则，不含领域术语（术语一律查 SKILL.md 术语表）。

---

## 〇、总纲

1. **连接词不追求替换，追求准确。** 既有的「但 ＞ 不过 ＞ 然而 ／ 即便 ＞ 尽管」等排序经实践验证有效，**保持不变**；改动应发生在**句法层面**而非词汇层面。
2. **连词不堆叠。** 同一句中出现两个逻辑连词时，删去承担力较弱的那一个，保留句法位置更靠近核心的那个。
3. **不无中生有。** 德语没有的总结标记、转折标记，中文不得自行添加。

## 一、转折 / 让步关系（adversativ / konzessiv）

### 1.1 基本译法

| 德语标记 | 译法 |
|---|---|
| aber | **但**（绝对主力） |
| jedoch / hingegen | 但 / 然而 |
| trotzdem / dennoch | 尽管如此 / 却 / 依然 |
| obwohl / wenngleich | **即便**（主导） |
| zwar … aber | 虽（然）… 但 … |
| vielmehr | 毋宁（是） |
| sondern | 而是 |

**要点**：「但」是主力而非「但是」；「但是」罕用；「不过」仅用于轻微转折。

### 1.2 ⭐ `Denn` 与让步成分嵌套时省略不译

**规则**：当 `Denn` 引导的句子内部已含让步成分（`bei aller + 抽象名词` / `zwar` / `obwohl`）时，
**`Denn` 不再译出**，由让步连词独自承担逻辑。

- ✗ 因为尽管他始终确信…　→　✓ **尽管**他始终确信…

**触发条件**：`Denn` + 句内让步插入语，尤以 **`bei aller + 抽象名词`** 为典型。
**反例**：`Denn` 引导**纯因果句**时照常译「因为」，**不可一概省略**。

> **德文**：Denn die Machtasymmetrie in den Angeboten des Internets hat ihn, **bei aller Überzeugung** von der grundsätzlichen Richtigkeit der Marktwirtschaft, immer umgetrieben und besorgt.
>
> **译文**：……**尽管**他始终确信市场经济原则上的正当性，互联网服务中的权力不对称却一直令他不安……

### 1.3 其他

- **反倒 → 反而**：「反倒」带口语色彩，改用「反而」（`stattdessen / im Gegenteil` 语境）。

## 二、因果关系（kausal）

### 2.1 基本译法

| 德语标记 | 译法 |
|---|---|
| deshalb / daher / darum | **因此**（主导） |
| weil / da / denn | **因为** |
| dadurch / damit / hiermit | **由此** |
| aufgrund / wegen | 由于 / 基于（少用） |
| angesichts | 鉴于 / 有鉴于此 |
| so dass / sodass | 从而 / 以致 |

### 2.2 ⭐ 因果紧密时并句（逗号连接，不另起句）

**规则**：`weil / denn` 从句与主句因果紧密、且从句较短时，**并入主句用逗号连接，不另起一句**。
断成两句会削弱因果的黏合度。

- ✗ ……根本就不合适。**因为**它们并不是……
- ✓ ……不适宜作为……**，因为**它们并不是……

### 2.3 ⭐ 固定短语的稳定译法（勿逐字直译）

| 德语 | 译法 |
|---|---|
| **In der Konsequenz** | **其结果是，**（句首＋逗号） |
| **Insgesamt** | **总体而言，** |
| **Im Ergebnis** | 其结果是 / 归根结底 |
| **Fazit und Ausblick** | **结论与展望** |
| **dem Umstand Rechnung tragen, dass …** | **考虑了如下事实：**…… |
| **d. h. / das heißt** | 也就是说 / 亦即 |

### 2.4 `damit` 的双义判别

`damit` 高频且多义，**须按功能分译，不可一律作「由此」**：

- **承接因果**（`damit` 作状语代副词）→ **由此 / 借此**
- **目的从句**（`damit` + 带动词的从句）→ **以便 / 以**（如「以便触达尽可能多的用户」）

## 三、总结 / 结论关系（konklusiv）

### 3.1 稳定译法

| 德语 | 译法 |
|---|---|
| Insgesamt | **总体而言，** |
| Im Ergebnis | 其结果是 / 归根结底 |
| Fazit und Ausblick | **结论与展望** |
| d. h. / das heißt | 也就是说 / 亦即 |
| kurzum / mit anderen Worten | 简言之 / 换言之 |
| letztlich / letztendlich | 最终 / 终究 |
| schließlich / abschließend | 最后 |

### 3.2 使用节制（重要）

总结类标记在德文学术文本中出现频率**远低于**转折与因果。

**不要**主动增添「综上所述」「总而言之」「总的来看」——
德语未出现 `zusammenfassend / kurzum` 等标记时，中文**不得**自行添加总结连接词。

## 四、精炼与去冗余

持续压缩指代词与冗语，使行文更紧：

| 冗 | 简 | 类型 |
|---|---|---|
| 以**这样一种**令人哀伤的方式 | 以**如此**令人哀伤的方式 | 压缩指代 |
| 以**这样一个**前提为出发点 | 以**如下**前提为出发点 | 压缩指代 |
| 它**顾及**了这样一个事实 | 它**考虑**了如下事实 | 动词精准化 |
| **反倒**掩盖 | **反而**掩盖 | 去口语 |
| 所**针对**的是 | **聚焦**于 | 动词精准化 |

**代词**：统一用「**其它**」（不用「其他」）。

## 五、文言与成语点缀的边界

| 结论 | 说明 |
|---|---|
| **可用** | 在结论段、强调句等关键位置**偶一为之**，可提升文气（如「使下述观点昭然若揭」）。 |
| **不得推衍为通则** | SKILL.md「用语」一节的**文言腔禁用词表仍然有效**；不得据此把「当然」改「然则」、「此处」改「于彼处」、「开始」改「伊始」。 |
| **不得牺牲准确度** | 意译成语须**不增损原义**。原文仅为 `anstatt eines Abstellens auf formale Aspekte`（而非着眼于形式要素）时，译作「削足适履」属过度增饰。 |

> **判据**：**默认直译，仅在全文 1–2 处关键位置点缀**，且点缀后不得改变命题内容、不得引入错字。

## 六、一页速查

| 我要译… | 用 | 不用 |
|---|---|---|
| aber | **但** | 但是 |
| deshalb / daher | **因此** | 故而 / 因而 |
| obwohl / wenngleich | **即便** | 哪怕 |
| Insgesamt | **总体而言，** | 总的来说 |
| In der Konsequenz | **其结果是，** | 在结果上 |
| Fazit und Ausblick | **结论与展望** | 结语与前瞻 |
| `Denn` ＋ 句内让步成分 | **省略 `Denn`** | 因为…尽管… ❌ |
| `weil` 从句（紧密、短） | **并句，逗号** | 另起一句 ❌ |
| `damit` ＋ 从句（目的） | **以便 / 以** | 由此 ❌ |
| 这样一种 X / 这样一个 X | **如此 X / 如下 X** | — |
| 反倒 | **反而** | 反倒 ❌ |
| 德语无总结标记 | **不译总结词** | 综上所述 / 总而言之 ❌ |
